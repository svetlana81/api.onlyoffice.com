URL

Save external URLs in a file list. When a saved link is opened, the corresponding resource launches in a new browser tab.

Installation​

Available by default in the DocSpace Saas solution.

You can enable it following the instructions here.

Configuration​

To start working with the plugin, you don't need to change the default settings.

In case you want to view the plugin metadata, such as the author, version, status, homepage, and description, go to Settings → Integration → Plugins and click next to the URL plugin.

Usage​

Creating a new URL​

To add a link to the file list:

  1. Open the Documents section or one of the available rooms.
  2. Click Actions → More.
  3. Select New URL.
  4. In the dialog box, specify the URL address and the link display name, then click Create.

The link appears in the file list as a .url file. When you click the item, the external resource opens in a separate browser tab.

Editing an existing URL​

To change a saved link:

  1. Right-click the .url item in the file list to open the context menu.
  2. Select Edit URL.
  3. Update the URL address and/or the link display name in the dialog box, then click Save.

Plugin structure​

Repository on GitHub: url.

All the required files are described here.

Interfaces​

The following plugin interfaces are used:

  • IPlugin. Required for each plugin. It contains the plugin status (PluginStatus) variable, used to embed the plugin into the DocSpace.
  • IApiPlugin. Required for API interactions with DocSpace (creating, updating, and reading .url files).
  • ISettingsPlugin and ISettings. Used to add a settings block for plugin configuration. Users can access this block from Settings → Integration → Plugins to view plugin metadata.
  • IMainButtonPlugin and IMainButtonItem. Used to add the New URL option to the Actions → More menu.
  • IContextMenuPlugin and IContextMenuItem. Used to implement the Edit URL context menu action for .url files.
  • IFilePlugin and IFileItem. Used to register the .url file type and open the stored link in a new browser tab when the file is selected.

Support​

If you want to request a feature or report a bug regarding this plugin, use the issues section on GitHub.
